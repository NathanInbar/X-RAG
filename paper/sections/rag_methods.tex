- Def: returns full article text as retrieved context
- Matters because it distinguishes "model can answer if information is present" from "retrieval found it"
- Expect to see that parrot saturates inclusion but with a massive mean context length and therefore poor conciseness.

\textbf{LeanRAG}
- Describe LeanRAGs introduction of hierarchical summarization, inter cluster relations , ..
